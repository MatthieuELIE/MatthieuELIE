### Matthieu ELIE — Frontend Developer

Frontend developer based in Bordeaux. Outside work I build small tools for my own workflow: Neovim plugins, Rust CLIs and an Obsidian plugin.

**Projects**

- [vault.nvim](https://github.com/MatthieuELIE/vault.nvim): per-project tasks and diary inside Neovim
- [comment.nvim](https://github.com/MatthieuELIE/comment.nvim): highlights, searches and inserts TODO/FIX/HACK/NOTE comments in Neovim
- [rust-todo](https://github.com/MatthieuELIE/rust-todo): a todo.txt editor in Rust, with a command line and a full-screen list
- [npm-audit](https://github.com/MatthieuELIE/npm-audit): turns `npm audit --json` into a colored report sorted by severity, with the fix command for each vulnerability
- [obsidian-pin-of-the-day](https://github.com/MatthieuELIE/obsidian-pin-of-the-day): opens and pins today's daily note in Obsidian
